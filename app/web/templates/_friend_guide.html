Dost ke liye setup guide (Hinglish)

Dost ko apna khud ka bot chahiye, jisme uski profile, uska resume aur uske Telegram pe jobs aayein, to wo is project ki apni copy chalayega. Sab free hai. Lagbhag 40 minute lagenge. Uski copy ka data, keys aur notifications tumhari copy se bilkul alag rahenge.

1. GitHub pe copy (fork)

  1. GitHub account banao, phir github.com/sanket801036/AI-Job-Hunter kholo aur upar Fork dabao.
  2. Fork me profile.yaml kholo, pencil icon se edit karo: experience_years, skills, titles_ok, locations_ok, skip_companies apne hisaab se bharo. Commit karo.
  3. Actions tab kholo aur "I understand my workflows, enable them" dabao.

2. Free accounts aur keys

  • Database: neon.tech pe free project banao, Connection string copy karo. Ye DATABASE_URL hai.
  • Telegram bot: Telegram me @BotFather ko /newbot bhejo, naam do, token milega. Ye TELEGRAM_BOT_TOKEN hai. Apne naye bot ko ek baar "hi" bhejo.
  • Chat id: Telegram me @userinfobot ko message karo, jo number mile wo TELEGRAM_CHAT_ID hai.
  • AI keys (kam se kam ek): aistudio.google.com se GEMINI_API_KEY, console.groq.com se GROQ_API_KEY, console.mistral.ai se MISTRAL_API_KEY. Jitni zyada keys, utna achha: ek fail ho to doosri chalti hai.

3. GitHub secrets

Fork me Settings → Secrets and variables → Actions → New repository secret. Ye sab daalo: DATABASE_URL, TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID, GEMINI_API_KEY, GROQ_API_KEY, MISTRAL_API_KEY. Phir Actions tab me "Scan LinkedIn jobs" → Run workflow dabake test karo. Telegram pe job aani chahiye.

4. GitHub token (scan chalane ke liye)

GitHub → Settings → Developer settings → Tokens (classic) → Generate new token. Scope me sirf repo tick karo. Token copy karke rakho, ye GITHUB_TOKEN hai. Kisi ko mat dikhana.

5. Render pe dashboard + Telegram commands

  1. render.com pe "Sign in with GitHub" → New Web Service → apna fork chuno, plan Free.
  2. Build command: pip install -r requirements.txt
  3. Start command: uvicorn app.web.main:app --host 0.0.0.0 --port $PORT
  4. Environment variables: upar wali saari keys, plus GITHUB_TOKEN, GITHUB_REPO = uska-github-naam/AI-Job-Hunter, DASHBOARD_PASSWORD = koi bhi strong password, WEBHOOK_SECRET = koi lambi random string (sirf letters aur numbers), PYTHON_VERSION = 3.11.9.
  5. Deploy ke baad link milega, jaise https://xyz.onrender.com. Usme login karke resume upload karo aur Search profiles set karo.

6. Telegram ko server se jodo

Browser me ye ek link kholo (apni values daal ke):

https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=https://xyz.onrender.com/telegram/webhook&secret_token=<WEBHOOK_SECRET>

"Webhook was set" aaye to ho gaya. Ab bot ko run now ya status bhej sakte ho.

7. Har 5 minute ka timer

cron-job.org pe free account → Create cronjob → URL: https://xyz.onrender.com/cron/scan?key=<WEBHOOK_SECRET> → schedule every 5 minutes → Test run me {"ok":true,"started":true} aana chahiye → Create.

Dhyan rakhne wali baatein

  • Bot sirf LinkedIn ke public job pages padhta hai, bina login ke. Tumhara LinkedIn account kabhi use nahi hota, isliye account pe koi khatra nahi.
  • Phir bhi LinkedIn ko automated reading pasand nahi, isliye timer 5 minute se kam mat karna. Kabhi kabhi LinkedIn ek scan rok deta hai (HTTP 429); agla scan wahi jobs utha leta hai.
  • Sirf apne liye use karo. Data bechna ya kahin publish karna nahi.
  • Keys aur tokens kabhi chat, screenshot ya GitHub code me mat daalna. Sirf GitHub secrets aur Render environment me.
